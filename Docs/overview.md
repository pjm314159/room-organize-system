# 机房排课系统

## 1. 项目概述

### 1.1 项目名称
机房排课系统（Computer Room Scheduling System）

### 1.2 项目类型
C语言 Demo 项目

### 1.3 项目简介
一个简单实用的机房课程安排管理系统，通过终端界面进行操作，使用SQLite数据库存储数据，实现机房课程的增删改查和排课功能。

### 1.4 主要特性
- 终端界面展示信息
- 菜单驱动操作
- SQLite轻量级数据库
- 代码简洁易懂

---

## 2. 选题背景

随着计算机教育的普及，各类院校和培训机构需要管理多个机房的使用安排。传统的人工记录方式容易出现时间冲突、资源利用率低等问题。

开发一个简单、高效的机房排课系统，可以实现：
- 合理分配机房资源
- 避免上课时间冲突
- 提高机房利用率
- 减少管理工作量

---

## 3. 功能说明

### 3.1 基础数据管理

#### 3.1.1 机房管理
- 添加机房信息（机房编号、名称、容量、设备状态）
- 查看所有机房列表
- 修改机房信息
- 删除机房（需确认）

#### 3.1.2 课程管理
- 添加课程信息（课程编号、课程名称、授课教师、所需课时）
- 查看所有课程列表
- 修改课程信息
- 删除课程（需确认）

#### 3.1.3 教师管理
- 添加教师信息（工号、姓名、联系电话）
- 查看所有教师列表
- 修改教师信息
- 删除教师（需确认）

### 3.2 排课管理

#### 3.2.1 创建排课
- 选择机房
- 选择课程
- 选择教师
- 选择上课时间（星期几、第几节课）
- 系统自动检测时间冲突

#### 3.2.2 排课查询
- 按机房查询排课情况
- 按教师查询排课情况
- 按星期查询排课情况
- 查看全部排课记录

#### 3.2.3 排课修改
- 修改已有排课的时间
- 删除不需要的排课记录

### 3.3 系统功能
- 查看机房使用统计
- 数据持久化存储

## 5. 数据库设计

### 5.1 数据表结构

#### 5.1.1 机房表 (computer_room)
| 字段名      | 类型    | 说明           |
|-------------|---------|----------------|
| id          | INTEGER | 主键，自增     |
| room_no     | TEXT    | 机房编号，唯一 |
| name        | TEXT    | 机房名称       |
| capacity    | INTEGER | 容纳人数       |
| status      | INTEGER | 状态：0正常/1维护 |

#### 5.1.2 教师表 (teacher)
| 字段名      | 类型    | 说明           |
|-------------|---------|----------------|
| id          | INTEGER | 主键，自增     |
| teacher_no  | TEXT    | 工号，唯一     |
| name        | TEXT    | 姓名           |
| phone       | TEXT    | 联系电话       |

#### 5.1.3 课程表 (course)
| 字段名      | 类型    | 说明           |
|-------------|---------|----------------|
| id          | INTEGER | 主键，自增     |
| course_no   | TEXT    | 课程编号，唯一 |
| name        | TEXT    | 课程名称       |
| teacher_id  | INTEGER | 外键，关联教师 |
| hours       | INTEGER | 所需课时数     |

#### 5.1.4 排课表 (schedule)
| 字段名      | 类型    | 说明           |
|-------------|---------|----------------|
| id          | INTEGER | 主键，自增     |
| room_id     | INTEGER | 外键，关联机房 |
| course_id   | INTEGER | 外键，关联课程 |
| teacher_id  | INTEGER | 外键，关联教师 |
| day_of_week | INTEGER | 星期几(1-7)   |
| period      | INTEGER | 第几节课(1-8) |

### 5.2 时间表示
- 星期：1-7（周一到周日）
- 课时：1-8（每天8节课）

## 7. 业务流程

### 7.1 创建排课流程
```
开始
  │
  ▼
显示可选机房列表 → 用户选择机房
  │
  ▼
显示可选课程列表 → 用户选择课程
  │
  ▼
显示可选教师列表 → 用户选择教师
  │
  ▼
输入星期和课时 → 验证输入格式
  │
  ▼
检查时间冲突？ ──是──→ 提示冲突，重新输入
  │否
  ▼
保存到数据库
  │
  ▼
提示成功 → 结束
```

### 7.2 时间冲突检测规则
- 同一机房、同一时间只能有一门课程
- 同一教师、同一时间只能有一门课程

## 8. 错误处理

### 8.1 输入错误
- 无效数字：提示"输入无效，请重新输入"
- 空输入：提示"输入不能为空"
- 超出范围：提示"选择超出范围，请重新选择"

### 8.2 数据错误
- 机房已满：提示"该机房此时段已有排课"
- 教师冲突：提示"该教师此时段已有课程"
- 删除确认：操作前要求确认"Y/N"

### 8.3 数据库错误
- 连接失败：提示"数据库连接失败"
- 操作失败：提示具体的SQL错误信息
